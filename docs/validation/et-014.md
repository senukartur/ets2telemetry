**Failures during development.** Each failure below was fixed before the runs above:

- A seeded random stream in `trip-reducer-replay.test.ts` found a reducer bug. A not-connected interval queued at a reconnection kept the monotonic bounds of its session. A plugin restart before the next commit then had the new session's first commit carry them, but storage registers source clocks under the committing session (T11). The fix strips the bounds of queued intervals when a new session of the game starts. The deterministic case "a queued not-connected interval of an earlier session drops its monotonic bounds…" reproduces it: it fails with the fix disabled and passes with it.
- Test-construction errors: a miscounted eventSeq in one case, a gap built before the events that precede it, and a hard-coded reconnect coverage. These were corrected in the tests; no expectation was changed to match reducer output.

## Fix round 1 (October 15, 2026)

Independent review pass 1 of `8fa5318` requested changes, and the verifier noted that the interval `detail` keys were undocumented. Fixed in `429e4e7` (code and tests) and the documentation commit that follows it:

| # | Finding | Change |
| --- | --- | --- |
| 1 | A regression set the session to `loading`, so the next job after a save load opened with a false `opened-at-load` cause | A regression never starts a load; it sets `running` when it occurred while running (T12, O10) |
| 2 | Fines, tolls and transfers while a job was known or likely active but untracked were `free-driving` | They are `ambiguous` while a checkpoint job is untracked or after a gap closed an active trip, until a clear or an outcome (concept.md, October 13, 2026) |
| 3 | An outcome resolving a reload check left a new trip open | The old trip closes as configuration-cleared, no trip opens, and the outcome stays `ambiguous` |
| 4 | A save-load continuation ignored `cargoLoaded`, and the re-send overwrote the trip's value | After a clear, a re-send with a different `cargoLoaded` is a not-merged continuation, and the closed trip keeps its value (concept.md, October 14, 2026) |
| 5 | Several effect shapes were never checked against real storage | New storage cases: case 22 (bounded reconnect interval on its own session clock), case 23 (`jobConfiguration: {eventSeq}`), cold-start restart close and same-session resume with seeds built from storage reads. The random streams now pass model seeds at plugin restarts and lose the reducer state at service restarts; both seed paths are counted (more than 5 each). The effect model checks that truck and trailer references name configuration events of the committing session |
| 6 | The outcome guard's residual risk was undocumented | Documented in [trips](../trips.md#attribution-t14) and the pending list |
| 7 | A continuation candidate survived a plugin-session change | It is relabelled `restart` at the new session |
| 8 | The caller contract did not require `disconnected` before each `session` input | Documented in [trips](../trips.md#caller-contract-for-et-015a) |
| Verifier note | Interval `detail` keys undocumented | [Interval detail keys](../trips.md#interval-detail-keys) |
