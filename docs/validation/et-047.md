# ET-047: Hard Mode page and full-width Live instrument

Date: October 23, 2026 (Europe/Warsaw). Task: [ET-047](https://trello.com/c/jPoJyaKb).

## Scope and design

Drive navigation is Live → Hard Mode → Journal. Hard Mode is a full page with status/count/progress, source/observation age, all twelve detected/required/state/reason/cvar entries, retained first loss, bounded Check again and read-only/persisted/manual-delivery caveats inline. The drawer and its trigger are removed. Supplementary hover/keyboard hints remain; essential content never depends on them. The Live instrument fills the content width. At narrow effective widths, conditions and telemetry reflow instead of forcing horizontal scrolling.

The ui-ux-pro-max skill informed visible active navigation, heading focus after navigation, keyboard operation, readable reflow, semantic status and contrast. Its generic design-system search returned unrelated immersive/marketing patterns; those suggestions were rejected. Verified navigation/accessibility and shadcn compound-card guidance was applied within the existing Yukon dark tokens, offline Onest and lucide family. No new design-system file or dependency is introduced.

The existing dashboard-lifetime controller, ET-026 evaluator/reader/proof, trip qualification, storage, IPC and native contracts are unchanged. UI, current guidance and the interactive mockup now reflect the owner's October 23 no-drawer decision; dated validation evidence remains historical.
