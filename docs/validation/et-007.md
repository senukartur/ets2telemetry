A diagnostic-only rebuilt test reproduced the failure and observed `IsIconic=1`, `GetClientRect=0x0`. Production was corrected to keep valid minimized window identity with explicit `client_bounds_available=false` and empty bounds. The retained regression expects this actual unavailable geometry. Subsequent full native and console ASan checks passed after the source change; neither timeouts nor expected values were loosened to hide a failure. Additional tests then covered actual display movement and persistent hidden-window ambiguity. No unchanged retries or false manual passes were used.
