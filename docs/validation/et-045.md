## Established causes

- **Item 1, gauge movement at displayed 0.** `desktopLiveView` rounded the speed text with `fixed(speed, 0)` but kept the unrounded `speedRatio`. The Live gauge draws the speed arc whenever the ratio is above 0, and its `stroke-linecap: round` paints a dot even for a tiny arc, so an SDK speed that flickers just above and at zero made a dot blink while the number read `0`. No CSS transition is involved. The inner RPM arc follows the real idle RPM and is not part of the defect.
- **Item 4, raw market.** The live card and the journal showed `job.market` verbatim, for example `quick_job`.
- **Item 5, truck id.** Protocol v0 carries only the truck model id; the SDK-localized brand and name arrive only in protocol v1, and decision F4 kept every v0-carried row on v0.
- **Items 10 and 11.** The overlay labels were "SDK average consumption" / "SDK mean" (RU "Средний расход по SDK" / "Расход SDK") with an extra strip caption, and the overlay income used telemetry-core's `formatMoney`, which appends "(SDK-documented)".
- **Item 14, Installed apps icon (ET-045g, not changed here).** `forge.config.cjs` sets no `iconUrl`, so electron-winstaller 5.4.4 falls back to Electron's `electron.ico`. Squirrel's `CreateUninstallerRegistryEntry` downloads the icon to `<root>\app.ico` only when that file is absent and sets `DisplayIcon` only in that branch, so the atom icon persists across updates. This is read from configuration and the primary source code; it has not been checked against an installed entry.
- **Item 12** (strip outside the client after a preset change): cause unknown. The hypothesis to test in ET-045c is the ordering of a height decrease and a move at 150% DPI.

## ET-045a changes

- **Standstill gauge.** The speed ratio is 0 while the displayed integer is `0` and keeps its fractional precision above it. Unavailable or stale speed still has no ratio; RPM, raw readings and history are unchanged.
- **Job market labels.** The five SDK 1.15 values show Cargo market, Quick job, Freight market, External contracts and External market (RU: Рынок грузов, Быстрый заказ, Грузоперевозки, Внешние контракты, Внешний рынок) on the Live card, its Job badge and the journal trip details. Unknown values and `(empty)` stay verbatim. telemetry-core, the v1 projection, storage and the JSON export keep the raw value. The Russian wording is a review point.
- **Truck name.** While both sources are current and v1's truck model id equals v0's, the truck row shows v1's brand and name (else name, else id); otherwise v0's id. No id-to-model table exists, so no model name is invented.
- **Overlay consumption.** Labelled "Consumption" / "Расход" in every layout and in the section toggles; the strip caption is removed. The value is still the SDK mean with the same conversion and availability; the dashboard keeps "SDK average consumption" and its note. The internal id `sdk-consumption`, the settings keys and the strip width reservation are unchanged.
- **Overlay income.** `formatMoneyAmount` shows `1234567 EUR` without the suffix, and an unknown currency still reads `(currency unknown)` / `(валюта неизвестна)`. `formatMoney` and the dashboard, journal and export texts are unchanged.

No settings format, IPC/preload, wire, storage, export format, overlay payload type, native code or installer configuration changed. The details are in [live telemetry fields](../live-telemetry-fields.md) and [the minimal overlay](../minimal-overlay.md).
