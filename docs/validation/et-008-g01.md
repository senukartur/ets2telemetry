## Corrections and controlled evidence

Negative-zero correction e916d0d1354398c41ed80cb4f1ca4e0454310cea changes only the final display string -0.0 to0.0. Canonical m/s values and nonzero reverse-speed signs remain unchanged. Genuine -0.001m/s inputs reproduced failures in both ETS2/ATS on old code; the corrected focused suite passed25/25, with rounding-threshold, signed reverse, unavailable/stale and canonical-value protection. Independent source review, typecheck, scoped ESLint and diffcheck passed. Corrected in-game display remains pending.

The manual direct-process launcher used SW_HIDE for the first GUI window. Controlled no-game comparison on the unchanged original9ed package reproduced no targetable app window while app/service were alive. Changing only startup Show toSW_SHOWNORMAL produced a targetable main window and readable service-ready UI. The background launcher console remains hidden. The manual setup command now uses WindowStyle Normal; production window/IPC/native code is unchanged.

A first20-second visible diagnostic reached its cap before the close input; that124 result and input failure remain recorded. A separately reviewed60-second no-game probe then closed the uniquely observed app window through Computer Use. Raw APP_STOP_REQUESTED, SERVICE_EXIT0, APP_EXIT0 and helper Job0 at11:34:29.4396192UTC corroborate natural app/service shutdown before the cap; no owned processes or temporary probe remained. This validates the launcher and non-game exit, not ordinary exit with an active game.

After the owner closed ETS2, exact receipt-owned DLL/license files were removed with hashes/path/reparse and closed-game guards. All nine unrelated names, lengths and SHA256 values were unchanged, with no additions. An initial whole-JSON comparison failed because filename sort order differed across PowerShell versions; per-file semantic verification passed. The failed comparison remains retained rather than rewritten.
