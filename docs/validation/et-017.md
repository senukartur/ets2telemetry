## PR-2: Steam discovery and manual game folders (October 17, 2026)

Branch `feat/et-017-steam-discovery`, base `main` `1bc41fe`. PR-2 adds read-only, injectable modules in `apps/desktop/src/plugin-setup/`: `vdf.ts`, `steam-discovery.ts`, `steam-registry.ts`, `game-folder.ts`, `game-processes.ts` and the shared `fixed-program.ts`. Nothing calls them from main yet. The test helpers `tests/shared/guarded-fs.ts` and `tests/shared/fake-steam.ts` confine every test to fake roots in a temporary folder.

### Isolation

- Every discovery and folder test reads through the guarded file system and fails if any path outside its temporary root was requested, also when the code under test caught the refusal.
- The one real registry run writes a Cyrillic SteamPath into `HKCU\Software\ETS2Telemetry-Test-<uuid>` and reads it with the fixed script, whose key names are replaced by that test key; the recorded scripts are asserted not to name Valve's keys. The key is deleted after the test; after the runs below, no `ETS2Telemetry-Test-*` key remained under `HKCU\Software`.
- The one real `tasklist` run only lists processes.
