## Reproduction

With the documented Node and Visual Studio/CMake tools on PATH:

```powershell
npm run typecheck
npm test
cmake -S native/telemetry-client -B native/telemetry-client/build -A x64
cmake --build native/telemetry-client/build --config Release
ctest --test-dir native/telemetry-client/build -C Release --output-on-failure
cmake -S native/telemetry-client -B native/telemetry-client/build-asan -A x64 -DETS2TELEMETRY_CLIENT_ASAN=ON
cmake --build native/telemetry-client/build-asan --config Release --target telemetry-pipe-client-asan telemetry-client-test-asan
ctest --test-dir native/telemetry-client/build-asan -C Release -R native-pipe-client-asan --output-on-failure
```

MSVC's x64 binary directory must be on PATH for its ASan runtime DLL. The controlled fixture, transport files and process handles are isolated from user history/game installations. CTest's 30-second external cap covers the console control.
