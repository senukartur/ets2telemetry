## Failed intermediate evidence and correction

The first ASan run passed the unchanged protocol corpus in 24.77 seconds but reported **stack-overflow** in the adapter test harness. Many approximately 46-KiB snapshot locals in one fixture function exceeded the instrumented console stack. Fixture snapshots were moved to explicit `std::unique_ptr` heap ownership; production callback cache remains bounded member storage. An intermediate fixture-edit compile error was followed by an accidental rerun of the previous binary, reproducing the same stack overflow; that stale-binary run is not evidence of rebuilt code. After correcting the edit and rebuilding successfully, the adapter ASan test passed, followed by the final selected 2/2 run above. The original failure is retained here; the tests were not skipped or given a larger stack. Initial ordinary compile errors (DWORD pointer type and DLL-export linkage) were fixed with correctly typed local DWORD storage and the official-example `.def` export pattern. The optional ASan linker warning was resolved by adding `/DEBUG`, without suppressing warnings.
