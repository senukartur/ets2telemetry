# ET-045b: contextual Game plugin card action results

Date: October 24, 2026 (Europe/Warsaw). Task: package b of [ET-045](https://trello.com/c/OmNYTBsp), item 15 only.

## Owner observation and cause

During the ET-044 installed check of ATS folder selection, the owner cancelled the folder dialog, had an empty invalid folder refused, and chose the actual ATS folder that Steam had already found. The answer "Эта папка игры уже найдена через Steam." appeared as an ordinary paragraph at the bottom of the Game plugin card, below "Export diagnostics…" and its note, far from the ATS button. It was easy to miss, and it did not say which action or game it concerned. The owner's evidence stays local under `.local/validation/et044-installed-20261023-cca3e16/folder-choice-report/`; no screenshot or log is copied into the repository.

Cause on base `b80e1532bc65999c7a6fe5aa482f487b2d9b4a19`: every card action wrote its answer into one card-wide `<p role="status" data-testid="plugin-result">` after the diagnostics note, with neither the action, the game nor a severity.

## Change

Renderer only. No IPC channel, bridge method, preload, main, contract type, settings format, wire, storage, export format, native code or installer changed, and `GAME_HISTORY_RECORDING` is unchanged.

- `apps/desktop/src/plugin-action-result.ts`: the pure model. Each call site names its action and game; exhaustive maps over the contract codes give every answer a severity (information, done, refused, failed); the localized title "{severity} — {action}" and the existing fixed answer texts are built at render time. A successful switch change, Retry or opened folder shows no invented result.
- `apps/desktop/src/action-result.tsx`: the reusable result body (Yukon tone, 3 px left border, icon and severity word) and its live region. Information, done and refused appear in a persistent polite `role="status"` region; a failure appears alone as `role="alert"`.
- `apps/desktop/src/plugin-setup-card.tsx`: one current result per card, shown in the region right after its trigger or the trigger's row; the trigger names it in `aria-describedby`; pending controls are `aria-disabled` behind a single-flight guard and keep focus, and focus returns to the trigger only when it was lost. The bottom `plugin-result` line is removed, and the mode note is `role="note"`.
- `FOLDER_DUPLICATE` now reads "This game folder is already found through Steam; nothing changed." / "Эта папка игры уже найдена через Steam; ничего не изменено." and is information, never an error.
- New EN/RU keys `act.*` for the severity words and action names. Russian severity words and titles are an owner wording review point.

The rules are in [game plugin setup](../plugin-setup.md#the-game-plugin-card) and the reusable pattern in [the UI specification](../design/ui-spec.md#et-045b-action-results--october-24-2026).

## Excluded surfaces and known limit

The pattern is adopted by the Game plugin card only. The Journal export result, the uninstall card result, the settings, overlay, autostart and language save messages and the Hard Mode lines keep their presentation; each is a follow-up candidate, kept out to bound this package to item 15.

Main answers "Open game plugins folder" with nothing that proves the folder opened, and when Windows cannot open it main only logs `PLUGIN_FOLDER_NOT_OPENED`. That failure is therefore not shown; showing it would need an IPC contract change, which is out of scope. A rejected call is still shown as a failure.
