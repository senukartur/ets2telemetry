# ETS2Telemetry

Windows x64 telemetry utility for ETS2 and ATS, including TruckersMP: a C++17 SCS SDK plugin streams over named pipes to an Electron/React/TypeScript app with a dashboard, a game overlay and a SQLite trip history.
